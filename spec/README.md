# 英语学习资料库 · 中文检索系统 Spec

## 一句话结论

15,000 条带中文翻译字段的英文学习资料，用 **PostgreSQL 单库 + pgvector + pg_trgm + B-tree + BGE-M3 / bge-reranker-v2-m3** 实现中文非精确检索。单词类（10,000）走词典义项的确定性路径；短语与句子类（5,000）走「精确短路 → 宽召回 → verifier 三分类」的语义路径。两路共用同一套动态准入条件与打标规则，不引入 Elasticsearch、独立向量库或任何中间件。

## 核心约束速查

- 「索引不到」的定义是**没有精确对应**，不是「没有返回结果」。
- 命中判定权只在 L2 verifier，不在相似度分数。
- 联想扩展在主路径，但**本身触发打标**。
- 并列精确对应（词典多义项、多个共识译法）全部返回，**不打标**。
- S0 只允许精确相等短路，不允许模糊相似短路。
- 在线路由动态准入，**不按 `corpus_type` 硬分流**。
